# URL 编解码

入口：左侧「开发工具 → URL 编解码」、首页工具卡片或 `/tools/url-codec`。输入、输出自动按框宽折行；折行只改变显示，不添加实际换行。

## 三种模式

| 模式           | 编码                                                                                          | 解码                                                |
| -------------- | --------------------------------------------------------------------------------------------- | --------------------------------------------------- |
| URL 组件，默认 | 使用 `encodeURIComponent`，适用于单个参数值、路径片段                                         | 使用 `decodeURIComponent`，普通 `+` 不变            |
| 完整 URL       | 使用 `encodeURI`，保留 `://`、`/`、`?`、`&`、`=`、`#` 等结构                                  | 使用 `decodeURI`，`%2F`、`%3F` 等保留字符仍保留转义 |
| 表单字段值     | 单个字段值按 `application/x-www-form-urlencoded` 字符规则编码，空格变 `+`，真正的加号变 `%2B` | `+` 变空格，`%2B` 变加号；严格校验 UTF-8            |

表单模式处理整个输入作为一个字段值，不拆解 `a=1&b=2`，不删除重复参数、不排序，不进行 URL 解析或地址归一化。它使用表单的字符转义规则，但对非法转义和 UTF-8 明确报错，不沿用宽松表单解析器替换非法字节的行为。

| 操作          | 输入           | 输出                         |
| ------------- | -------------- | ---------------------------- |
| 组件编码      | `中文 a+b`     | `%E4%B8%AD%E6%96%87%20a%2Bb` |
| 组件解码      | `a+b%2Bc`      | `a+b+c`                      |
| 表单字段解码  | `a+b%2Bc`      | `a b+c`                      |
| 完整 URL 解码 | `%2f%3F%23%26` | `%2f%3F%23%26`               |
| 组件解码一次  | `%252F`        | `%2F`                        |

已有 `%` 编码会再次编码，例如 `%20` 编码成 `%2520`；每次只处理一层，不自动反复解码。支持中文和 Emoji，保留前后空格、换行、BOM、控制字符及 Unicode 组合形式，不自动 `trim`。

## 错误、处理与下载

- `%`、`%2`、`%GG` 提示转义错误；`%E4%B8` 提示 UTF-8 序列不完整；`%FF`、过长编码、代理区或超过 Unicode 范围的字节明确拒绝，不输出替换字符。
- 两个方向均拒绝孤立 UTF-16 代理字符，避免转换时静默丢失内容。
- 错误行列和「定位错误」选区对应原始输入，包括 CRLF、Emoji 及表单模式的加号。
- 默认启用小文本自动处理：输入不超过 200 KiB，停止输入约 300 毫秒后处理。可关闭；大文本手动点击「开始编码 / 开始解码」。
- 输入上限 1 MiB，按 UTF-8 字节计算；输出上限 3 MiB。超过限制的粘贴会保留当前输入，不静默截断。
- 每次处理在独立 Worker 中进行，最长 5 秒；可停止、重试。清空或离开后，迟到回复不能恢复旧内容。
- 输入、方向或模式变化后，旧结果暂停复制和下载，重新处理成功后启用。
- 「复制结果」复用现有剪贴板兼容实现；「下载 TXT」保存 `url-encoded.txt` 或 `url-decoded.txt`，保留实际 UTF-8 文本，下载不加入 BOM 或换行。输入自身包含的 BOM 和换行保留。

## 本地边界与维护

页面首次加载依赖桌面或 Web 服务提供静态资源；转换在浏览器 Worker 内完成，不访问输入地址、不执行输出内容、不发送文本到网络。内容仅保存在当前页面内存，清空、刷新或离开后释放，不写入历史、日志、localStorage 或业务备份。

工具注册使用 `execution: "browser"` 和 `apiNamespace: null`，没有 `/api/v1/tools/url-codec` 内容处理 API。桌面 LAN 沿用现有浏览器工具页面规则；业务备份仍为原有八项。没有新增运行时依赖、模型或能力包。

实现集中在 `apps/web/src/features/url-codec/`：`processor.ts` 负责转换和校验、`processor.worker.ts` 负责消息、`useUrlCodec.ts` 负责页面任务生命周期、`page.vue` 负责交互；测试与实现同目录。标准行为参考 [ECMAScript URI 函数](https://tc39.es/ecma262/multipage/global-object.html#sec-uri-handling-functions) 和 [WHATWG 表单编码](https://url.spec.whatwg.org/#application/x-www-form-urlencoded)。
