# 表格批量归档

入口：“多媒体内容归档 → 表格批量归档”。支持小红书、抖音和 TikTok 混合链接，复用现有获取、下载、归档、翻译及文件安全机制。

## 使用流程

1. 点击“下载 Excel 模板”获取空白 `.xlsx`；也可选择“下载 CSV 模板”。两种模板均只含“作品链接”和“平台”表头，不含示例数据。Excel 模板已冻结表头，并为前 100 行提供平台下拉选项。
2. 第一条非空行必须是表头，必填列为“作品链接”，平台列可留空自动识别。支持别名“链接 / 分享链接 / url / link”和“平台 / 来源平台 / platform”。其余列忽略，不导入作品元数据。
3. 每行放一条作品链接或只包含一个链接的分享文案。平台可填“自动识别 / 小红书 / 抖音 / TikTok”或相应英文标识。
4. 选择文件，查看逐行校验结果。无效链接、平台不符及表内重复行不会执行。
5. 已归档作品默认跳过；如确实需要重新获取，明确选择“重新获取并刷新已有归档”。可指定成功结果的目标分组，然后点击“确认并开始归档”。
6. 在窗口中查看行号、平台、进度及结果。后端服务保持运行时，可关闭导入弹窗或浏览器页面，批次继续执行；重新打开后从历史批次查看。退出后端服务后的恢复规则见下文。
7. 结束后可重试失败项、导出结果 CSV，或只删除批次记录。成功作品使用原来的详情、下载、翻译、截帧和删除入口。

| 作品链接                   | 平台     |
| -------------------------- | -------- |
| 单条 TikTok 视频或图集链接 | TikTok   |
| 单条小红书分享链接         | 自动识别 |
| 单条抖音分享链接           | 抖音     |

## 限制与取消规则

- 文件最大 **2 MiB**，每批最多 **100 条非空数据记录**，最多 50 列，单元格最多 10000 字符。
- Excel 只读取第一张可见工作表，保留其原始行号；不读取其他工作表。CSV 使用逗号分隔，支持 UTF-8/BOM、UTF-16LE BOM 和 GB18030，允许引号、逗号及单元格内换行。
- 不支持 `.xls`、`.xlsm`、加密工作簿。链接或平台列中的公式需要先粘贴为纯文本；不执行公式、不跟随外部工作表引用。
- 一次执行一个批次，一次仅向原有队列提交一个批次子任务；两次成功提交至少间隔 7 秒。手动获取仍按原规则运行，队列满或同一链接正在处理时等待，不放大原有 16 条等待上限。
- “停止后续任务”取消尚未执行的批次项目；当前已运行的作品按原规则完成，原子提交过程不被中断。不会取消其他手动任务。已经保存的作品保留。
- 已识别已有作品的刷新绑定原归档 ID；排队或执行期间删除、替换原归档时，不会由迟到结果重新创建它。
- 等待中的批次也计入原有“忙碌”保护，防止在两条子任务之间误启动环境深检、能力卸载或数据迁移；仍沿用原来的退出确认及强制退出规则。
- 一个项目失败不阻断后续项目。“重试失败项”创建新的批次，只包含失败及程序中断的项目；无效、重复、已跳过和主动取消项不会自动重试。
- 服务退出或重启不会自动重新抓取；中断项目需手动重试。已完成的子任务会在恢复时核对，避免把已保存结果误报为未完成。
- 最多保留 100 个批次记录，达到上限时需手动删除旧记录；没有自动清理批次或作品的 TTL。删除批次记录只删除调度元数据，不删除任何归档作品、媒体、翻译或截帧。
- 平台登录、网络、代理、访问限制、媒体配额及可选翻译能力仍按现有规则处理，不能保证所有公开链接都可获取。

## 技术与数据兼容

### 自定义作品分组

- 列表上方支持新建、重命名、删除分组，以及“全部分组 / 未分组 / 指定分组”筛选。选中作品后可移动到目标组，或移回“未分组”。每个作品属于至多一个分组，最多 200 个分组，名称 1～80 个字符，名称前后空白会去除，同名分组不能重复创建。
- 分组筛选与平台、类型、搜索、分页及“补全未翻译内容”的范围同时生效；切换分组会清空当前选择并返回第一页。
- 删除分组只解除分组关系，其作品变为“未分组”，不会删除任何作品、媒体、翻译或截帧。作品刷新、重启不丢失分组；删除作品时同时移除其分组关系。
- 表格导入中的目标组只应用于本批次获取或刷新成功的作品。已跳过、无效、重复、失败或主动取消的项目不会移动已有作品。没有指定目标组时，新作品保持未分组，已有作品保持原分组。
- 目标组在导入执行期间被删除时，不重建该组，也不再移动后续结果。重试失败项会复用仍存在的目标组；目标组已删除则不指定分组。
- 分组关系与批次成功进度在同一个数据库事务内提交。后续轮询不会覆盖用户手动调整过的分组；数据库保存失败时两者一起回滚。
- 分组及关系存入现有 SQLite `entities` 表的 `archive-group`、`archive-group-member` kind，不改写作品清单、媒体目录或数据库 Schema。保留分组需同时备份应用数据库，单独复制作品媒体及清单不包含分组关系。

上传表格只在内存中解析，不写入用户素材目录；确认后只持久化链接、原始行号、处理方式及结果。批次使用现有 SQLite `entities` 表的 `archive-import-batch` kind，不增加数据库迁移，不改变现有归档结构或保留规则。

CSV 导出保留原始行号、原链接、原平台、识别平台、中文状态、进度、原因、错误码和归档 ID。所有字段正确转义；可能被 Excel 当作公式执行的文本加前导单引号，避免执行表格中的公式内容。

XLSX 在 API 端使用已存在的 ZIP 读取能力和固定版本 `fast-xml-parser`，不增加前端表格解析库、模型或 Python 依赖，也不修改已签名能力包。[XML 解析器来源](https://github.com/NaturalIntelligence/fast-xml-parser)。文件条目数、解压总量、XML 大小和嵌套深度有上限，拒绝 DOCTYPE/ENTITY 声明；不执行宏、远程访问或磁盘解包。

中性任务 DTO 增加可选 `skipped`，表示短链解析后发现已有作品并在下载前跳过。原小红书兼容接口继续移除该新增字段，旧请求和响应保持兼容。

## API

基础路径 `/api/v1/tools/media-archive/import`，写操作继续受管理员会话、精确 Origin/CSRF、请求大小及限流保护。

| 方法   | 路径                       | 说明                                                                                                                                      |
| ------ | -------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------- |
| GET    | `/template.csv`            | 下载可用 Excel 打开的模板                                                                                                                 |
| POST   | `/preview`                 | multipart 单文件 `file`；返回校验预览，不开始获取                                                                                         |
| POST   | `/batches`                 | `{ sourceName, sheetName?, existing: "skip" \| "refresh", groupId?, rows: [{ rowNumber, inputUrl, inputPlatform }] }`；重新校验后创建批次 |
| GET    | `/batches`                 | 批次摘要，最多 100 个                                                                                                                     |
| GET    | `/batches/:id`             | 批次及逐行进度                                                                                                                            |
| POST   | `/batches/:id/cancel`      | 停止后续项目                                                                                                                              |
| POST   | `/batches/:id/retry`       | 从失败项创建新批次                                                                                                                        |
| DELETE | `/batches/:id`             | 删除已结束的批次记录                                                                                                                      |
| GET    | `/batches/:id/results.csv` | 导出当前结果，执行中也可下载快照                                                                                                          |

预览不是执行凭证：服务端在创建及逐条入队时重新校验输入和已有归档状态。导入任务不会接管已经存在的相同链接任务；子任务与批次的归属先落库，再允许实际排队，防止记录保存失败后仍开始获取。

分组基础路径为 `/api/v1/tools/media-archive/groups`，写操作沿用现有管理员、CSRF 及维护保护，读取沿用现有 LAN 只读规则：

| 方法   | 路径      | 说明                                                                                               |
| ------ | --------- | -------------------------------------------------------------------------------------------------- |
| GET    | `/`       | 读取分组列表                                                                                       |
| POST   | `/`       | `{ name }` 创建分组                                                                                |
| PATCH  | `/:id`    | `{ name }` 重命名分组                                                                              |
| DELETE | `/:id`    | 删除分组并解除关系，保留作品                                                                       |
| POST   | `/assign` | `{ groupId: string \| null, itemIds: string[] }`，原子移动最多 100 个已保存作品；`null` 表示未分组 |

作品列表接口及按筛选范围补全翻译支持可选 `groupId`：`all`、`ungrouped` 或分组 ID。中性列表项增加可选 `groupId`；旧小红书接口不返回该字段，已有作品与媒体 DTO 不变。Excel 模板作为前端静态资源进入普通构建，离线桌面使用同一文件，无需临时生成或联网下载。
