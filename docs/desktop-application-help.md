# Windows 桌面应用使用帮助

## 安装位置与数据

安装时请选择当前 Windows 用户有写入权限的目录。安装器会显示最终应用目录并检查写入能力；受保护的 `Program Files` 等位置不适用于此用户级安装模式。

Windows 安装版的应用数据默认保存在：

```text
<安装目录>\data
```

数据库、作品与任务历史、个人素材、模型、可选能力、浏览器登录状态、日志和备份都由应用保存在此根目录或其子目录中。系统或第三方组件自行管理的临时缓存不属于应用可完全控制的存储范围。请为所选磁盘预留足够空间，并定期将重要数据备份到其他位置。

## 可选能力

在“设置 → 能力管理”中查看和安装转写、配音、AI 图片处理、小红书归档/翻译等可选能力。安装前可查看下载量、预计空间、网络要求和来源信息。安装不会在打开功能页或提交业务任务时悄悄开始。

能力可单独重装或卸载。卸载能力只移除该能力的运行时、依赖和模型；作品、历史任务、素材、登录状态等个人数据会保留。共享依赖仍被其他能力使用时，设置页会阻止卸载并说明原因。

## 旧版本迁移

如果第一次启动时检测到旧版 `%LOCALAPPDATA%\EcommerceToolboxData`，应用会先显示迁移来源、目标位置和空间预估。选择“迁移”会把受管数据复制并校验到所选安装根下的 `data`；旧源目录不会被删除，可用于回退。也可以明确选择以空数据开始，但旧目录仍会保留。

迁移期间不要强制结束应用或手动移动源、目标、临时和备份目录。若应用检测到中断，会先恢复一致状态再继续；若摘要校验失败，请停止操作并保留目录与日志。

## 卸载、重装与升级

普通静默卸载、应用升级和安装器重装都会保留 `data`。卸载后重新安装到同一目录即可继续使用保留的数据。

只有在交互卸载向导中主动选择删除数据，并连续通过两次确认，才会清理应用管理的数据。该删除不可通过重装撤销；卸载前请先备份。静默卸载始终保留数据，不会弹出或绕过删除确认。

## 网络和发布资产

能力安装需要连接设置页说明的 HTTPS 资产源；部分在线配音或第三方服务还需要持续联网。下载过程会校验已签名 manifest、文件长度和 SHA-256。网络中断或校验失败不会替换现有健康能力版本，可在能力管理中查看错误并重试。

本项目当前供组织内部使用。依赖来源、能力包签名与 SPDX SBOM 用于资产追溯和故障排查；使用帮助中的来源或许可信息不是用户需要逐项审批的安装流程。
