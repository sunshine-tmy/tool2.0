# Windows 桌面应用使用帮助

## 安装位置与数据

安装时请选择当前 Windows 用户有写入权限的目录。安装器会显示最终应用目录并检查写入能力；受保护的 `Program Files` 等位置不适用于此用户级安装模式。

Windows 安装版的应用数据默认保存在：

```text
<安装目录>\data
```

数据库、作品与任务历史、个人素材、模型、可选能力、浏览器登录状态、日志和备份都由应用保存在此根目录或其子目录中。系统或第三方组件自行管理的临时缓存不属于应用可完全控制的存储范围。请为所选磁盘预留足够空间，并定期将重要数据备份到其他位置。

## 可选能力

视频去字幕在“视频与文案 → 视频去字幕”打开，先安装 `video-ai` 基础包（依赖 Python 3.12、FFmpeg）。NVIDIA 设备可选装 `video-ai-cuda` 加速 Big-LaMa。当前可用极速（OpenCV）和快速（Big-LaMa）两档，STTN/ProPainter 未随包提供。输入视频不改动，成功结果长期保留，可从处理记录预览、下载、删除；“数据备份与恢复”可单独选择视频去字幕记录及结果。详见[交接与验证记录](./video-ai-release-handover.md)。

在“设置 → 能力管理”中查看和安装配音、AI 图片处理、小红书归档/翻译等可选能力。安装前可查看下载量、预计空间、网络要求和来源信息。安装不会在打开功能页或提交业务任务时悄悄开始。

如果目标电脑无法访问在线资产源，可以先在网络可用的电脑上点击能力卡片显示的 GitHub 发布页，下载列出的全部同版本 .tar.gz 文件，再通过“离线导入”一次选中这些文件。不要改名、解压或混用不同版本；应用会按照随应用内置的签名目录检查文件名、大小、SHA-256、包内文件清单并执行安装后自检。上传仅发生在本机，导入本身不会访问下载源；该能力缺少的共享依赖（例如对应 Python 运行时）需要先单独安装或离线导入。传输过程中可取消；校验或自检失败不会替换当前可用版本。

能力可单独重装或卸载。卸载能力只移除该能力的运行时、依赖和模型；作品、历史任务、素材、登录状态等个人数据会保留。共享依赖仍被其他能力使用时，设置页会阻止卸载并说明原因。

### 导出已安装能力，在另一台设备离线导入

1. 在能力卡片点击“导出离线包”，选择应用数据、运行时和模型目录之外的保存位置。
2. 导出得到 `.toolbox-capabilities.zip` 文件，自动包含该能力及其共享依赖的签名文件（包括模型）。导出大模型可能耗时较长，可点击“取消导出”；离开设置页也会取消尚未完成的导出，未完成文件不会作为最终备份保留。
3. 将文件复制到另一台设备，在**同一能力卡片**点击“离线导入”，选择这个 ZIP。应用先校验全部文件，再按依赖顺序安装并重建 Python 环境，不需要另行下载能力资产。

两台设备必须具有相同的系统/架构和相同的内置能力目录版本。待更新的能力需先更新再导出；旧版 Python 3.11 仅保留卸载入口。这个 ZIP 是可重新导入的签名文件快照，不等于发布页原始 `.tar.gz` 分卷，不要解压或放入源码启动的 `offline-resources/components/` 冒充原安装包。相同依赖可能包含在多个导出包中，分别导入时会重装这些依赖，现有任务或播放占用时会阻止操作。

能力导出不包含作品、任务历史、个人素材、登录信息、私钥或生成的 Python 环境。迁移业务内容请另外使用“数据备份与恢复”。导入时仍需为备份包、解包和 Python 环境预留空间；在线服务的联网要求保持不变。

## 旧版本迁移

如果第一次启动时检测到旧版 `%LOCALAPPDATA%\EcommerceToolboxData`，应用会先显示迁移来源、目标位置和空间预估。选择“迁移”会把受管数据复制并校验到所选安装根下的 `data`；旧源目录不会被删除，可用于回退。也可以明确选择以空数据开始，但旧目录仍会保留。

迁移期间不要强制结束应用或手动移动源、目标、临时和备份目录。若应用检测到中断，会先恢复一致状态再继续；若摘要校验失败，请停止操作并保留目录与日志。

## 卸载、重装与升级

普通静默卸载、应用升级和安装器重装都会保留 `data`。卸载后重新安装到同一目录即可继续使用保留的数据。

只有在交互卸载向导中主动选择删除数据，并连续通过两次确认，才会清理应用管理的数据。该删除不可通过重装撤销；卸载前请先备份。静默卸载始终保留数据，不会弹出或绕过删除确认。

## 网络和发布资产

### 在局域网中使用桌面主机

桌面应用启动后，通过顶部网络图标或“设置 → 局域网访问”查看、刷新和复制使用地址。地址使用当前网卡和实际监听端口；默认端口被占用时会自动换用空闲端口，请复制页面显示的地址，不要自行固定端口。多网卡时可选择与另一台设备同网段的地址。

在同一可信局域网的其他设备上，用浏览器打开该地址即可使用六个业务模块，包括上传、生成、队列进度、音视频预览与下载。任务、模型和数据仍在桌面主机上处理和共享，访客也能修改或删除业务数据；不要向不可信网络或公网共享。依赖能力须先在主机安装并就绪，在线服务仍要求主机联网，平台登录等需要主机交互的步骤仍在主机完成。

使用期间请保持桌面应用开启。关闭应用后，共享服务也会停止。系统设置、能力安装、诊断报告与环境修复不向局域网开放。

如果其他设备打不开地址，请确认处于同一局域网、没有访客 Wi-Fi/AP 隔离或 VPN 干扰，并按需自行确认系统防火墙允许应用接入专用网络。地址显示只代表网关已监听，不代表已验证另一台设备的连通性；应用不会自动修改防火墙、代理或网络权限。

能力安装需要连接设置页说明的 HTTPS 资产源；部分在线配音或第三方服务还需要持续联网。下载过程会校验已签名 manifest、文件长度和 SHA-256。网络中断或校验失败不会替换现有健康能力版本，可在能力管理中查看错误并重试。

本项目当前供组织内部使用。依赖来源、能力包签名与 SPDX SBOM 用于资产追溯和故障排查；使用帮助中的来源或许可信息不是用户需要逐项审批的安装流程。
