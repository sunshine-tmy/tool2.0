# JSON 格式化

入口：左侧「开发工具 → JSON 格式化」，或首页工具卡片；地址为 `/tools/json-format`。

## 使用方式

1. 输入或粘贴标准 JSON，也可以选择或拖入一个 UTF-8 编码的 `.json` / `.txt` 文件。
2. 选择 2 空格、4 空格或 Tab 缩进，点击「格式化」；「压缩」输出单行 JSON。原始输入保持不变。
3. 校验失败时查看行列位置，点击「定位错误」返回输入位置。输入、缩进或输出模式变化后，旧结果标记为过期，完成重新处理前不能复制或下载旧结果。
4. 使用「复制结果」或「下载 JSON」保存当前有效结果。导入文件的下载名保留原名称并使用 `.json` 后缀；直接输入默认下载为 `formatted.json`。
5. 「清空」同时清除输入、输出和提示；处理期间可点击「停止处理」。

默认对不超过 200 KiB 的输入在停止输入约 300 毫秒后自动处理；可关闭自动处理。更大内容需要手动点击处理按钮。

## 内容与保留规则

- 接受对象、数组、字符串、数字、布尔值和 `null`，不执行 JavaScript，不自动修复单引号、注释或尾随逗号。
- 格式化和压缩只改动字符串之外的空白。数字原文（含大整数、`1.2300`、`1e3`、`-0`）、字段顺序及字符串转义保持不变。
- 同一对象中重复字段仍全部保留，并给出提示；转义后相同的字段名也会提示。最多显示前 20 条提示，同时显示总提示数。
- 导入时识别文件开头的 UTF-8 BOM，输出不携带 BOM，并显示提示；非 UTF-8 文件明确拒绝。
- JSON 内容不上传、不写入数据库、localStorage、日志或业务备份。离开或刷新页面释放输入和结果；用户主动复制及下载的内容由用户保存。
- 页面首次加载仍需桌面端或 Web 服务提供页面和脚本；页面加载后，JSON 处理不依赖外部网络、模型或后端业务接口。

## 资源边界

| 项目     | 限制                                                           |
| -------- | -------------------------------------------------------------- |
| 输入     | 最大 5 MiB，按 UTF-8 字节计；超限文件与粘贴不替换当前输入      |
| 嵌套     | 最大 256 层；超限属于资源限制，不表示 JSON 语法错误            |
| 输出     | 最大 20 MiB，避免缩进造成过量膨胀                              |
| 后台任务 | 每次最多运行 5 秒，可停止、重试；新输入和离开页面终止旧 Worker |

宽屏双栏、900px 及以下上下排列。只使用现有 Vue、Naive UI 与浏览器 Worker，没有新增依赖或能力包。

## 开发落点与接入

实现集中在 `apps/web/src/features/json-format/`：`processor.ts` 管理严格语法和无损空白处理，`processor.worker.ts` 是后台入口，`useJsonFormatter.ts` 管理状态与生命周期，`page.vue` 组合界面。

工具注册表增加 `execution: "browser"`、`apiNamespace: null` 的分支；原有八个服务端工具保持原字段值。桌面 LAN 网关只开放新页面及已存在的静态资源路径，不为本工具添加业务 API 前缀，不放宽管理接口。纯前端工具不产生持久化业务数据，业务数据备份仍为八项，JSON 输入不纳入备份。

为满足原有 150 KiB 入口预算，首页改为路由懒加载，页面地址与功能不变；其他懒加载块仍保持 75 KiB gzip 限制。
