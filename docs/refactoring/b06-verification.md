- `apps/api/src/__tests__/app.test.ts` 每项使用独立临时根，显式提供七项 RuntimeLayout 路径。
- 使用真实 `getConfig` 和 `createApp`，关闭 dotenv 读取；环境仅包含测试默认值和当前场景的显式配置，不继承宿主配置。

- 仅复制 Git 源码中的 `clear-generated.mjs` 和 `cleanup-engine.mjs`，通过真实清理子进程检查分类及非法路径，不执行仓库目录的清理脚本。清理引擎从自身位置推导根目录，仅改 cwd 不足以隔离。

- 递归删除前检查临时父目录、专用前缀和符号链接；重复 dispose 复用同一 Promise，dispose 后拒绝新启动。
