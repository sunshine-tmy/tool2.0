### 保持不变的契约

目录读取失败仍按空列表处理；单份 JSON 解析、可读性检查或导入写入失败仍按原方式跳过，文件原样保留，继续其他文件并设置原标志。
已有标志时不重新扫描；数据库读出的不可读 payload 不改写、不删除。
原结构判定不替换为公开 API Schema，不补日期、尺寸或其他此前未有的严格校验。

有结果的旧任务先清除旧过期时间，再写领域记录、登记内存、写统一任务投影，最后刷新队列位置；无结果任务不新增永久保留。
save 时仅有结果且已离开 pending/running 才清除过期时间；领域写入及统一投影在同一同步执行段按原顺序发生。
失败照原样传播，不在适配器中增加回滚、事务、错误映射或成功事件；原 create/processComposition 等调用方继续负责回滚和最终状态。
