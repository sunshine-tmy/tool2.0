# 启动与环境诊断

入口位于设置区 `/settings/diagnostics` 和顶部服务状态；不是业务工具。桌面主服务启动失败或运行中退出时，受限本地窗口仍可复制摘要、导出报告及退出。仅启动失败且尚未进入业务状态时提供显式重试，不提供未知运行状态下的强制重启。

桌面启动窗口实时推送阶段，并以单个在途请求轮询兜底。显示已完成的真实步骤数、总等待和当前阶段用时；等待动画只表示尚未收到阶段完成事件，不是耗时百分比。主界面实际加载完成后才关闭启动窗口；同阶段等待超过 15 秒给出继续等待或查看日志的提示。状态桥接缺失、请求失败或无响应时明确显示同步异常，不静默保留空白，也不声称后台仍在正常工作。重试会清空上次进度，旧快照不能覆盖新阶段。

## 使用

- 轻检读取必要目录、数据库及组件状态，访问本机 Worker 的轻量诊断接口，不加载模型、合成或下载。
- 可选组件未安装为中性；CPU 回退为警告；模型待命不报错。尚未检查在线合成时明确显示未验证。
- 深检逐项执行：组件签名工件与安装自检、图片/克隆模型加载、固定英文短句在线合成。
- 深检有取消按钮。子进程收到取消后等待退出再清理；不可中断的模型调用显示取消中，保持维护锁直至安全结束，不误杀用户服务。
- 正在运行/排队的通用及领域任务、安装、上传或任意音频播放阻止深检与恢复。播放心跳丢失时保守拒绝；重新打开同一页面可更新本会话状态。不会自动中断工作。
- 旧版已安装能力包不包含新 Worker 接口时，显示兼容性无法确认，需要用户在空闲时显式更新对应能力。不会静默绕过包签名加载仓库脚本。

## 开发诊断

运行 `pnpm run doctor`；JSON 使用 `pnpm run doctor --json`。必须使用 `run`，因为 `pnpm doctor` 是 pnpm 自带命令。工具复用后端配置解析，遵循开发代理和 `VITE_DEV_PORT`，不打开数据库、不安装、不清端口、不写配置。存在故障时退出码为 1，不代表执行过修复。

Windows 启动器增加 `-DiagnoseOnly`；已有参数不变。自动打开浏览器前验证工具箱服务身份及数据库/存储就绪。前端默认后端目标跟随 `API_PORT`，仍可通过 `VITE_API_PROXY_TARGET` 覆盖。

## 安全和报告

诊断接口只接受本机 socket 及本机页面来源，不信任转发地址、不对 LAN 网关开放。修复只接受固定能力 ID，不能执行任意命令、传入 URL 或本机文件路径。现有管理员和 CSRF 校验保持。

报告仅包含受控诊断文案、状态、原因码及版本；可选择附带本次结构化事件，不包含用户文案、文件、数据库、环境变量、原始日志或登录凭据。报告只本地导出，桌面端由用户选择文件位置，Web 使用浏览器下载。

诊断日志每文件 5 MiB，最多三份，子进程管道持续消费但仅记录白名单错误码。写日志失败时保留最近 500 条内存事件，不覆盖原始故障。

源码修改不会更新已安装的桌面包或签名能力包。发布需单独构建桌面及更新对应能力包，并完成 Windows / Apple Silicon 安装版验收。自动化测试不代替用户视觉检查。

## 桌面退出

- 窗口关闭、菜单退出共用退出握手。空闲时不弹确认框；存在任务、等待队列或播放时可取消退出。安装、环境维护、迁移及仍在提交的写请求阻止退出，用户确认不能绕过此保护。
- 用户确认后，后端同步复查并冻结所有新写入（包括诊断操作），返回 `APP_SHUTTING_DOWN`。桌面销毁业务 renderer 停止 HTML/WebAudio 及队列播放，保留不依赖后端的本地关闭提示。
- 正常顺序是停止队列并持久化中断状态、关闭领域运行时和模型 Worker、关闭数据库、复核进程退出。显示真实阶段，不显示估算百分比。等待和活动任务记录保留，标明退出中断，需手动重新生成；批次参考音色、文案、已完成作品和已下载模型不会删除。
- 任务收尾、模型服务、数据库阶段预算分别为 15 / 10 / 5 秒，总宽限不超过 30 秒；重复或倒序阶段不能延长截止时间。超时进入受控进程清理，再等待真实退出结果。
- Windows 在后端初始化前通过系统 PowerShell 建立独立 Job Object 保护进程。后端及其后代自动继承保护，包括动态端口 Worker、短命令和浏览器；不按端口、名称或模糊路径杀进程，不提升权限。守护管道关闭（包括桌面主进程崩溃）触发整组回收；后端意外退出同样回收所属进程。
- Windows 退出需确认受控 Job 活动进程数为零；回收失败不记录“退出完成”，保留提示。若系统禁止 PowerShell 或 Job 绑定失败，后端不会绕过保护继续启动，显示启动失败。该机制不管理用户独立启动的开发服务，也不卸载模型文件。
- 非 Windows 保留正常的队列、子服务退出及主进程退出确认；Windows Job 的异常退出整组兜底不适用于其他系统，仍需单独安装版验收，不宣称跨平台强制回收完全等价。
- 退出阶段、正常完成、超时、强制回收写入现有脱敏诊断日志；不记录任务正文、原始命令或进程输出。源码测试不构建桌面安装包，安装版退出与视觉检查由用户单独执行。
