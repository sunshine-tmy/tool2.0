# UUID 生成

入口：左侧「开发工具 → UUID 生成」、首页工具卡片或 `/tools/uuid-generator`。首版为 [RFC 9562 UUID v4](https://www.rfc-editor.org/rfc/rfc9562.html#name-uuid-version-4)，RFC 9562 已替代 RFC 4122。

## 生成与展示

- 默认数量 5 条，支持 1～10,000 的整数；空值、零、负数、小数和超过上限的数量禁用生成，不静默截断或取整。
- 点击「生成 UUID」后生成一批，默认小写、带连字符、每行一条。首次打开不自动生成。
- 完成后整批替换当前结果；生成过程中显示进度，并暂停复制和下载，不暴露半成品。
- 修改数量只影响下一次生成，页面始终显示当前结果的实际条数，并在数量不同时提示下次生成数量。
- 大小写、连字符和输出格式只调整展示，不消耗新的随机数，不改变 UUID 身份。内部结果保持小写、带连字符的标准形式；无连字符为紧凑展示形式。

| 输出格式       | 下载         | 说明                         |
| -------------- | ------------ | ---------------------------- |
| 每行一条，默认 | `uuids.txt`  | 使用 LF 分隔，无额外末尾换行 |
| 逗号分隔       | `uuids.txt`  | 使用英文逗号分隔             |
| JSON 数组      | `uuids.json` | 字符串数组，缩进 2 空格      |

结果区自动按宽度折行并纵向滚动；显示折行不改变实际内容。复制复用现有剪贴板兼容实现，下载内容与当前格式化结果一致，不添加 BOM。剪贴板换行形式受浏览器和系统影响。

## 随机数、分块和异常

- 统一使用 `crypto.getRandomValues()` 获取每个 UUID 的 16 字节随机数据，并设置 v4 版本位和标准变体位。实现不依赖仅在安全上下文提供的 `crypto.randomUUID()`，兼容桌面、Web 和支持 Web Crypto 的局域网 HTTP 页面。[Web Crypto 接口](https://www.w3.org/TR/webcrypto/#Crypto-interface)
- 每块最多 256 条，一次随机数请求最多 4,096 字节，低于原生接口的 65,536 字节限制；块间通过定时器主动让出主线程，允许停止，无需 Worker 或新增依赖。
- 每批检测重复 UUID，重复候选最多额外重试 16 次。连续重复或安全随机数不可用时明确报错，不使用时间戳、序号或 `Math.random()` 生成后备 UUID。
- v4 提供概率性的全局唯一性；本工具检测当前批次内重复，不维护跨设备或跨会话去重记录。
- 生成时固定该批数量；重复点击不会创建并行任务。停止或失败时保留上一批完整结果并提示，本次不完整结果丢弃，可重新生成。
- 清空或离开页面停止后续分块；旧的定时回调不能恢复已清空的结果。刷新或返回该工具均重新从空状态开始。

## 本地边界与维护

随机生成、格式化和下载均在浏览器本地执行。页面首次加载需要桌面或 Web 服务提供静态资源；UUID 不上传、不写入数据库、历史、日志、localStorage 或业务备份。仅用户主动执行复制和下载。

工具注册为 `execution: "browser"`、`apiNamespace: null`，`acceptedTypes: []` 表示无需输入文件，没有 `/api/v1/tools/uuid-generator` 生成 API。复用现有桌面 LAN 页面规则，业务备份仍为原有八项。

实现集中在 `apps/web/src/features/uuid-generator/`：`generator.ts` 负责随机数、v4 位规则、批次去重与输出格式，`useUuidGenerator.ts` 负责分块生命周期，`page.vue` 负责交互，三份测试同目录。项目原有临时 ID 工具及业务 ID 行为保持不变。
