# 归档视频编辑：文字预设样式

## 范围与结构

- 移除智能检测入口、场景切点/静音检测任务、轮询接口和结果应用逻辑。
- 文字预设放在「文本」tab 内，位于文字基础设置与位置大小之间。
- 第一项为「无样式」，后续按描边、投影、色块编排。使用 T 字缩略图预览效果，悬停显示中文名称。
- 使用声明式列表维护预设，新增组合无需修改控件结构。沿用蓝紫选中态，窄面板自动换行。

## 应用与保留

- 点击立即更新选中文字的颜色、描边、投影和底色，一次操作可撤回。
- 保留文字内容、字体、字号、粗斜体、下划线、间距、横竖排、位置、变换和时间。
- 「无样式」恢复白色文字并清除描边、投影与底色。
- 手动修改颜色后仍保留其他效果；只有实际参数完全匹配时才高亮对应预设。
- 锁定素材和处理中状态下禁用预设。

## 渲染与验证

- 外观参数作为可选字段写入原有字幕配方，旧字幕沿用黑色描边默认效果。
- Canvas 预览与 ASS 导出共用外观默认值；底色按完整文本块计算，支持多行与竖排。
- 测试覆盖样式切换清除残留、保持非外观字段、撤回、配方校验、预览绘制及导出标签。
- 不引入外部字体、模型或新依赖；实屏效果由用户验收。

## 花字扩展

- 「文本」下增加「基础 / 花字」二级 tab，字体、位置与混合设置继续归入基础。
- 花字先提供「无花字」和「烈焰蓝字」两项。后者采用白色字面、白蓝黄粉多层描边，以及逐行铺设的红橙黄色静态火焰。
- 花字 ID 使用独立可选字段保存；切换到普通预设时清除花字效果。
- 采用同源矢量路径在 Canvas、缩略卡片和导出中绘制，随换行、竖排、位置、缩放、旋转与不透明度生效。
- 第一款会设置加粗和基础外观，保留内容、字体、字号、时间和位置；每次选择可单独撤回。
- 导出使用 [ASS 绘图与描边标签](https://aegisub.org/docs/latest/ass_tags/)，不依赖联网素材或运行时图片下载。
