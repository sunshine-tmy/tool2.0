正式实施范围、资产大小、测试结果与限制见 [UI 接入记录](implementation.md)。本目录的 `index.html` 仍是独立评审样机，不是正式应用入口。

## 打开方式

双击本目录 `index.html`，无需安装依赖、启动服务器或连接网络。

- 首页：分类、关键词搜索、13 个工具入口。
- 顶部“图标核对”：查看全部独立 PNG，以及 48px / 32px 图片框对照。
- 顶部“效果图”：首页和全部 13 个主模块，共 14 张独立页面；支持按模块切换。
- 每个布局样机标题右侧的“查看本模块效果图”可直接定位对应页面。
- 点击首页工具：查看对应模块的布局样机；全部 13 个入口可进入并返回首页。

样机顶部常驻设计说明，不会读取现有数据库、用户记录、模型、登录状态或能力环境。业务操作按钮只展示说明，不处理、删除或上传文件。选择本机视频仅在浏览器内预览；切页与离开时释放 Object URL。文本工具的小型纯浏览器交互用于评审，不替代正式模块的完整协议、文件模式、大小限制或校验。

## 视觉规范

- 主色 `#6558FF`，辅助青蓝 `#25C7DA`，画布 `#F6F5FF`。
- 主文字 `#182033`，次文字 `#697386`，边框 `#E6E5F5`。
- 系统中文字体；正文 14px，工具名称 17–18px，工具页标题 26px，首页标题 32–36px。
- 顶栏 64px，搜索 52px，常规控件约 40px。
- 面板圆角 14px；卡片间距 16px；工作区间距 20px；面板内边距 20–22px。
- 图标按主体边界调整显示宽度，维持接近的视觉重量。图标核对页保留原始留白，供查看源文件的真实情况。
- 首页在宽屏使用四列，依可用空间切换三列、两列、单列。局域网传输使用横向入口，在窄屏恢复普通卡片。
- 模块页不放全模块侧栏，保留返回首页；复杂模块可以拥有内部的参数侧栏、分组或时间线。
- 绿色只用于明确状态；危险操作不使用主色装饰。加载、焦点、不可用与错误状态使用文字辅助。

## 各模块的布局落点

| 模块         | 内页布局                                                                       |
| ------------ | ------------------------------------------------------------------------------ |
| 图片压缩     | 左输入与结果、右参数；预设、格式、质量和尺寸                                   |
| AI 图片      | 功能 Tab、图片工作区、参数、长期留档；商品图编辑保留独立工作面                 |
| 多媒体归档   | 获取/导入、分组、筛选、选择操作、卡片/列表、居中详情；配乐与水印保留独立编辑页 |
| 视频去字幕   | 预览、参数侧栏、时间线、区间与框选、处理记录                                   |
| 多国语言配音 | 引擎 Tab、有序分段、语言/音色/设备配置、队列、批次记录                         |
| 音频素材库   | 来源/分组筛选、素材列表、应用级播放、回收站与预设                              |
| 音频提取     | 输入视频、音轨、码率、队列、结果波形与下载                                     |
| 音频转换     | 输入队列、码率、去重提示、转换记录与入库                                       |
| JSON         | 处理工具栏、双栏输入输出、校验与复制                                           |
| Base64       | 编解码选项、双栏文本、文件处理与结果操作                                       |
| URL          | 编解码选项、双栏文本、结果操作                                                 |
| UUID         | 数量/格式设置、生成结果、复制与下载                                            |
| 局域网       | 地址/二维码、文件/图文 Tab、传输、记录与权限状态                               |

布局落点是视觉组织要求，完整功能以现有实现为准。设计样机有意只实现页面选择、分类搜索、部分模式切换、输入展示和小文本操作，没有模拟整套业务状态机。

- Node 语法检查通过。
- DOM 环境验证 13 个路由与资源、首页分类搜索、JSON 成功/失败状态、中文 Base64、URL、UUID v4、图标/效果图总览、按指针添加区间和 Object URL 释放。

尚未声称完成：

- 未进行浏览器截图、实屏小尺寸视觉验收或 Windows/macOS 的真实窗口验收，由用户查看设计总览确认。

`screens/*.png` 是图像生成的示例状态。模型会重绘图标，部分文字、数值、控件细节可能与正式实现不一致，不作为字段、功能或行为契约。准确的独立资产映射以 PNG 清单及本地 HTML 为准。例如均衡档位仍然对应现有 STTN，而不是图中泛化的档位描述；音频效果图省略了部分外壳区域，实际样机仍统一使用顶部栏。

## 本轮补齐的页面

图片压缩、AI 图片处理（抠图状态）、多国语言配音（参考音色克隆状态）、音频素材库、音频格式转换、Base64 编解码、URL 编解码、UUID 生成和局域网文件传输，共 9 张。

配音图曾出现多选语言的初稿，已针对性修正为单语言配置，并将批次操作放到记录第二行；丢弃的初稿未纳入交付。效果图使用的是示例内容，不代表真实模型、真实转换结果或用户数据。数字、字符、选项、按钮可用条件与精确文案在实施时必须以现有代码核对，不能直接从图片复制成业务规则。

新增 9 张图及其提示词已加入 `screen-manifest.json`，`screens.js` 维护首页和 13 个模块的展示顺序及对应关系。图库使用延迟加载，避免首次打开同时解码全部原图。整个设计目录约 33.55 MiB，仍与产品运行时资源分离。

本轮新增验证：14 张页面 PNG 可解码且摘要互不相同；13 个模块的效果图入口、图片标题、下拉选中值对应一致；全部页面切换、首页图片、未知筛选回退以及原首页搜索通过 DOM 检查。检查中发现的下拉值同步问题已修复并复验。未执行截图验收或业务构建。

范围为 13 个首页工具的主页面，尚未展开每个 Tab、详情弹窗、商品图/配乐/水印子编辑器以及系统设置页面的全部状态图；这些既有功能仍保留，不能因主页面效果图未展开而删除。
