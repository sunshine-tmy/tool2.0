## 样式与状态归属

- 公共 Token、外壳和首页仍归 `styles/ui-v2.css`；本轮未增加平行主题。
- 四个开发工具共用 `shared/ui/tool/DeveloperWorkspace.css`，选择器受 `.ui-v2` 和页面类约束。算法、Worker 和状态仍由 feature 拥有。
- 其余布局在既有 feature 的 scoped 样式或配音样式文件中，没有引入组件库、状态框架或通用任务层。
- 归档通过具名 slot 组合批量入口，原组件、ref 和事件不变；单测替身同步渲染 slot。
- 音频库折叠只影响显示，队列和播放器保持挂载；展开真实波形后宽度有效，未自动播放。
- 帮助收起时保留全文；错误、权限、不可用和任务状态仍直接展示。

参考图的示例数据和简化控件不覆盖实际功能。UUID 保留文本输出以支持三种格式和大批量；音频库保留队列和回收站；配音保留授权和完整参数；视频保留完整时间线。没有制造假归档、生成假模型结果或替换真实波形。

本轮未重新设计所有详情弹窗、商品编辑器和每种媒体的全部子状态。它们继续使用现有交互和主题。未运行真实模型或平台下载任务，桌面原生窗口、macOS 和安装包级验收仍待对应平台验证。
