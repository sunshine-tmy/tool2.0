# 归档视频素材快捷工具

时间线工具栏在删除按钮之后依次增加旋转、镜像、倒放、定格图标；使用现有浅色工作台按钮与 Lucide 图标，提供中文悬停说明和无障碍名称。无适用视频、轨道锁定或任务进行中时禁用。

| 工具 | 操作规则                                                                                                                                           |
| ---- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| 旋转 | 选中视频每次顺时针增加 90°，与右侧位置大小中的旋转参数同步，可多选操作。                                                                           |
| 镜像 | 切换选中视频的水平镜像，可多选操作。                                                                                                               |
| 倒放 | 切换选中视频片段的播放方向及原声方向，保留源区间、变速、音量和空间变换。静帧不需要倒放。                                                           |
| 定格 | 必须选中一个包含当前指针的视频；取该源帧插入默认 3 秒静帧。当前片段按指针拆开，同轨后续片段顺延 3 秒，其他轨道的绝对时间保留。同轨后续锁定时禁用。 |

静帧作为无声的视频轨道片段显示，缩略图重复当前帧；保留来源及变换，支持移动、复制、拆分、裁剪、变速和删除。静帧记录源取帧位置及独立时长，保存时生成对应静止画面，无需创建孤立图片文件。

所有操作进入同一撤销/重做历史和粗剪草稿，重新打开后恢复；预览与保存/导出共用时间映射。倒放片段的左右裁剪按播放顺序调整源边界，波形和缩略图同步倒序。

倒放预览复用现有可取消的视频编辑任务，弹窗显示进度；处理成功后切换方向，失败或取消保留原片段。同一源范围只准备一次，后续范围内裁剪、变速、音量与淡入淡出复用缓存。导出和预览均分块反转画面及原声，避免整段倒放缓存占用过多内存。
