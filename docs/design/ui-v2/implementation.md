## 代码归属

| ------------------------------------------------ | ---------------------------------------------------------------------- |
| `apps/web/src/styles/ui-v2.css`                  | 新主题值、外壳、首页与跨模块展示规则，作为最后一个 `components` 层加载 |

CSS 保留 `tokens → foundation → components` 层级。R11 原始文件及其历史摘要保留；新层在 `r11-style-amendments.json` 独立登记。检查完整验证新层的来源、唯一性、最终位置及全部结构后，只在 AST 副本上移除该层，再验证原始冻结级联。未登记的历史改动仍会失败。

这是一轮有意改变视觉的实施，不再使用旧 R11 像素相同作为新视觉目标。没有删除旧门禁、提高预算、扩大 CSS 忽略或接受新截图来掩盖差异。

## 复跑命令

在仓库根目录使用现有 Node/pnpm 开发环境：

```powershell
pnpm dev:web
pnpm --filter frontend test --maxWorkers=2
pnpm typecheck
pnpm lint
pnpm lint:architecture
pnpm deadcode
node --test tooling/quality/styles.test.mjs
pnpm exec playwright test --config playwright.ui-v2.config.ts
pnpm build:web
git diff --check
```

浏览器测试使用 Playwright 既有独立存储配置；若默认测试端口被占用，可先设置 `PLAYWRIGHT_API_PORT`、`PLAYWRIGHT_WEB_PORT`，不要终止无关程序。新增配置及设计样机的三个经典脚本均按真实消费者登记为 Knip 入口，未增加忽略项。
