# 归档视频统一编辑工作台

## 页面与操作

归档详情中的视频统一使用“视频编辑”入口。移除顶部粗剪、配乐、水印模式及保存后切换流程；左侧用“素材 / 音频 / 文本 / 水印”分类添加内容，右侧根据当前选中的元素显示属性。旧 `panel=audio`、`panel=watermark` 链接仍可进入同一工作台，并定位对应素材分类。

视频、音频、文本、水印共用工程草稿、撤销重做、时间线和一次最终保存。点击导出生成独立下载文件，并继续保留可编辑的实时预览；保存最新版本后，详情与下载改用新成品，原片保留。“恢复原始视频”重置整个工程并需确认。

时间线最低高度按两条最高的素材轨道、刻度、工具栏及底部信息的实际占用计算；只有一条素材时预留同高的第二条位置。分隔线拖动、键盘调整、恢复历史布局和缩小窗口均遵守该限制，更多轨道在区域内滚动。

图集生成视频完成后关闭生成弹窗并刷新当前归档，不自动切换到视频编辑器。需要继续编辑时，由用户点击生成视频的“视频编辑”入口。

## 水印轨道

上传或从水印库选择静态图片后，在当前指针处添加水印片段，默认居中、固定位置，并跟随成片结尾。拖动或裁剪片段后使用固定结束时间，也可在属性中重新开启“跟随成片结尾”。

- 可拖动到独立水印轨道，参与轨道排序、锁定、隐藏、框选删除、复制粘贴和撤销重做。
- `Q`、`W`、`Ctrl+B / ⌘B` 与视频、文本、音乐一样支持多选裁剪和拆分；`Ctrl+C/V / ⌘C/V` 使用编辑器内部片段剪贴板。
- 预览变换框支持移动、旋转、角点等比缩放和边缘单轴缩放；移动时复用画布中心及边缘吸附提示线。
- 属性分为基础、位置大小、运动；保留固定、直线、往返、反弹及关键帧运动。反弹水印拖动后以当前指针时刻的落点重新锚定运动起点，不平移或挤压整个碰边范围；运动面板九宫格调整起点、终点或选中关键帧。
- 暂停时选中运动水印显示轨迹虚线及起止点、关键帧位置，平移、缩放、裁剪后同步更新；播放、取消选择或隐藏轨道时不显示。辅助线不进入导出。
- `sourceStart` 保存源运动时钟。移动区间、左裁剪或中间拆分不会使保留部分的动画从头播放。

反弹预设共用同一组路径定义，预览绘制、轨迹规划与导出均引用它：

| 预设           | 路径规则                                                               |
| -------------- | ---------------------------------------------------------------------- |
| 经典斜向反弹   | 两轴独立碰边反射，完整周期为设置时间的两倍                             |
| Z 型折返       | 左上、右上、左下、右下四个固定顶点                                     |
| 多段锯齿反弹   | 从左上开始，保持原有左右交替且逐段向下的六个顶点                       |
| 交叉穿梭反弹   | 保留原有七个顶点及跨画面交叉顺序                                       |
| 长短交替反弹   | 保留原有八个顶点及长短段落顺序                                         |
| 多边不规则巡游 | 保留原有八个顶点和不同边界间的连接顺序                                 |
| 随机碰边巡游   | 固定种子生成八个碰边点，每四点覆盖全部四边；仅主动换随机路线时重抽种子 |

命名预设保留完整固定顶点，手动起点作为额外接入段，不替换预设首顶点。方向切换只镜像预设路线，不改手动起点或随机种子。相邻重复点不产生额外停留段。反弹及往返提示线显示完整运动周期，直线提示线显示至运动终点；这些规划辅助线不受剩余片段时长截断，实际播放、保存和导出仍严格遵守水印区间。

水印与文本共同按轨道层级绘制。上方视频遮挡下方视觉元素的时间段；没有视频的空隙保留黑色画布并显示未被遮挡的水印和文本。预览与导出使用同一几何、运动和层级规则。

## 旧工程与素材保留

打开旧工程时，一次性把全局音乐和水印迁移为轨道，记录 `studio.unified`，保留原声总音量及旧运动设置。保存统一工程时不再同时渲染旧全局音乐或旧全局水印，避免重复混音和重复叠加。旧归档记录仅在用户保存成功后更新。

音乐使用归档独立快照，水印使用 `studioWatermarks` 图片快照。复制片段复用素材引用，同一图片只保存一次；素材库中的原记录删除后，已保存工程仍可预览、编辑和再次保存。受控图片路由支持 Range，访问时固定文件租约。快照进入已有配额、备份与旧文件回收流程。

尚未保存的上传水印仍遵循原有 **24 小时草稿保留策略**。保存成功后才回收上传草稿；取消或处理失败保留可重试的草稿和原成品。过期或丢失素材会明确报错，用户需要重新选择图片。

## 最终输出

保存设置仍在开始处理前弹窗展示。智能补帧每次打开默认关闭；关闭时不执行补帧，开启后才展开处理选项。补帧作用于视频、文本、水印与声音已完成合成的整个成片，视觉边界包含水印区间，草稿编辑不启动补帧或下载能力包。

## 验证范围

自动化覆盖统一入口、整个工程提交、旧链接兼容、旧配方迁移幂等性、独立快照、删除素材库原记录后的二次保存、复制裁剪及撤销、运动时钟、预览吸附、取消任务和图集生成兼容。真实 FFmpeg 小样覆盖视频遮挡、水印与文字层级、音乐输入索引、裁剪后的运动连续性、旋转和透明度。桌面端实际拖拽手感与长视频导出仍需在用户现有素材上体验确认。
