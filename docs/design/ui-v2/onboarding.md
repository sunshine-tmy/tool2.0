# 新手操作引导接入记录

日期：2026-11-25。覆盖多媒体内容归档、视频去字幕、视频编辑、多国语言配音。

## 入口与学习方式

- 应用根部仅挂载一个悬浮引导入口，默认显示独角兽形象，桌面 80×80px、600px 以下 64×64px；入口设置可切回 48×48px 的 CircleHelp 简洁图标。首次不自动开启教程。入口距左右边缘 12px，初始在右侧可用高度的 65% 处。
- 复用 Naive UI 的 Tooltip、Modal、Button、Tag 和现有目录组件；角色与图标均通过原生按钮激活，拖动采用 VueUse `useDraggable`，移动超过 6px 才认定拖动，松手自动吸附到最近侧边。动画 180ms，遵循减少动画设置。
- 入口避开原生标题区、应用头部和底部安全区；保存左右侧和纵向比例。目录标题右侧的“入口设置”菜单提供靠左、靠右、重置位置，键盘可以打开入口。
- 业务弹窗、加载遮罩和全屏预览期间隐藏入口。引导进行时也隐藏入口，退出后恢复。
- 图文批量水印、配乐弹窗标题栏提供“新手引导”作为弹窗内入口，打开同一教程目录并展开图文处理分组；不关闭原业务弹窗或改动已选作品、设置。目录层级按来源弹窗计算，关闭后再进入原有教学上下文。页面只通过轻量请求状态通知异步目录，不同步导入教程 UI。
- 教程拆成 18 个独立章节，每章 3～7 步，使用稳定 `data-tour` 锚点定位。目录按模块、功能分组、章节分层展示；缺少真实素材或引擎不匹配时禁用对应详细章节并说明准备条件。
- 进度按教程版本和步骤 ID 保存。中途退出后用户可继续或从头开始；完成后可重新学习。位置与进度只存本机浏览器存储，写入失败使用会话内存，不新增后端接口或遥测。

## 独角兽形象与动效

2026-11-26 接入用户指定的浅紫独角兽：粉色/薄荷绿鬃毛、金色螺旋角、薄荷绿羽翼及奶油色肚皮。使用 imagegen 制作 1280px 高清透明母版及表情、躯干素材；小天使素材不参与项目引用。

- `GuideMascot` 仅负责展示并发出激活事件，由 `GuideCenter` 控制可见、拖动和减少动画状态；点击或 Enter/Space 直接打开现有目录，不增加欢迎卡片或另一套教程。
- 眨眼采用睁眼、半闭、闭眼、半闭、睁眼约 200ms 的序列，间隔随机 6～9 秒。生成的表情仅作为眼部补丁合成到固定躯干，避免全身闪变。
- 挥手为原图前爪的独立透明图层，固定肩部枢轴，以 12 个姿态关键帧通过 Web Animations API 连续插值 800ms；身体、头部、羽翼保持静止。只在细指针悬停时触发，完成后冷却 3 秒，无整图摇摆、常驻帧循环或全局鼠标跟随。
- 基础图先加载；动作资源动态导入并解码完后才启用，不阻塞点击。动作资源不可用时保留静态入口，基础图出错时临时回退图标，不修改用户偏好。
- 业务弹窗、目录、教程、全屏、后台标签页或拖动时停止动画和计时；恢复后从静止状态开始。减少动画模式不播放眨眼、挥手或吸边过渡。
- 显示方式保存于 `toolbox:onboarding:appearance:v1`；旧位置键 `toolbox:onboarding:position:v1` 与全部教程进度保持不变。统一使用 `[data-guide-trigger]` 恢复触发按钮焦点。
- 拖动边界按入口实际宽高计算，观察宿主尺寸与窗口变化，隐藏时不记录零尺寸；位置仍按左右侧和纵向比例保存。气泡朝页面内侧显示，拖动时关闭。

运行素材为 `assets/unicorn-*.webp`，统一 240×240px、带透明通道，共 64,614 字节（约 63.1 KiB）；其中初始静态图 16,106 字节。高清源图保存在本地 `docs/design/ui-v2/mascot-source/`，沿用已有 PNG 忽略规则，不打入前端。`scripts/export-guide-mascot.mjs` 使用已有 API 工作区 Sharp 导出、清理近透明杂点、合成固定眼部及前爪图层，资源尺寸、枢轴与字节数见 `unicorn-manifest.json`。

重新导出时传入 `--master`、`--half`、`--closed`、`--body` 四个 PNG 路径；可直接使用上述本地目录中的同名 `unicorn-*.png`。图片尺寸及构图变更时需同步检查导出脚本的眼部和肩部坐标；该脚本不启动任何业务模型。

## 目录层级与浏览方式

目录配置在 `directory.ts` 中独立声明，以现有教程 ID 引用章节，解析时校验每章恰好出现一次且属于正确路由。显示名称可以精简，不修改教程 ID、版本、步骤或进度记录。

| 模块           | 功能分组     | 目录章节                                            |
| -------------- | ------------ | --------------------------------------------------- |
| 多媒体内容归档 | 新手入门     | 获取与整理                                          |
| 多媒体内容归档 | 素材归档     | 本地视频批量归档、表格批量归档、TikTok 主页批量归档 |
| 多媒体内容归档 | 内容整理     | 归档详情与媒体操作、分组管理、英文编辑              |
| 多媒体内容归档 | 图文处理     | 图文批量加水印、图文批量配乐                        |
| 视频去字幕     | 基础流程     | 视频去字幕处理流程                                  |
| 视频去字幕     | 精细编辑     | 区间编辑、手动框选                                  |
| 视频编辑       | 开始创作     | 开始创作与草稿                                      |
| 视频编辑       | 编辑制作     | 编辑工作台                                          |
| 多国语言配音   | 参考音色克隆 | 基础操作、智能识别分段                              |
| 多国语言配音   | 在线配音     | 基础操作、智能识别分段                              |

- 复用 Naive UI `NTabs`、`NSelect`、`NCollapse`、`NDropdown`。一次只显示一个模块，功能分组可独立展开；章节使用带轻分隔线的紧凑列表行，保留学习状态、具体准备条件和开始/继续/重学操作。
- 点击悬浮入口时，当前页面属于已接入教程的模块（含子路由），目录仅显示该模块的引导；首页及没有对应教程的模块展示全部四个模块选项。桌面标签和窄屏下拉使用同一筛选范围。全部模块模式沿用本次会话上次浏览的模块，首次为归档。归档默认展开新手入门、去字幕展开基础流程、编辑器按主页/工作台展开，配音按当前真实引擎展开；其他分组收起。同次浏览切换模块时保留各自展开状态，重新打开时恢复默认展开，不写入新的持久化数据。
- 切换模块标签仅切换目录内容。跨模块浏览时，顶部统一提供“前往该模块”，章节行不显示启动按钮；实际跳转等目录关闭动画完成后再调用原路由，遵守未保存确认。取消时保留原页面和当前目录选择，不启动教程。成功后定位实际模块并展开对应默认分组，仍由用户点击开始。
- 工作台中的草稿教程提供“前往草稿主页”；草稿主页中的工作台教程保留真实工程前置条件。配音目录不替用户切换业务引擎。
- 弹窗最大宽度 720px，保留窗口及顶部安全边界；标题、说明和模块导航位于固定头部，仅功能列表滚动。600px 以下用模块下拉替代标签，章节操作换行；粗指针及窄屏主要操作至少 44 CSS px。入口位置操作收进标题右侧菜单，不再占据底部固定区域。
- 目录通过 `NModal` 卡片预设的 `header` 插槽渲染标题及模块导航，不同时传入 `title` 属性（当前 Naive UI 会优先使用该属性，覆盖整个自定义头部）；弹窗名称使用 `aria-labelledby` 关联可见标题。
- 本次目录整理未改动引导执行器和教学弹窗关闭适配，不增加依赖、后端接口或模型任务。

## 操作边界

引导可以直接展示登记过的无副作用业务弹窗，不模拟点击业务按钮。不上传、创建演示工程、切换引擎、改变素材选择、修改参数或提交/取消任务；不自动检测字幕、添加区间、开启框选或识别填入文案。

视频工作台需已打开真实工程且时间线加载完成。字幕区间和框选章节要求原视频已加载、可编辑且没有任务占用。配音章节要求引擎匹配。没有表格预览、区间或字幕框时讲解实际父区域，不伪造结果。

目录中的跨模块跳转沿用 Router 及已有未保存确认，跳转后仍由用户点击开始。目标元素最多等待 3 秒；条件性内容缺失时直接使用父区域，避免重复等待空步骤。业务快捷键在讲解期间被隔离，教程支持上一步、下一步、完成、结束和 Esc。路由改变、工程卸载、引擎切换或进入全屏会结束引导，清理观察器、遮罩与事件，并保留步骤。

## 细化章节与接入约定

| 模块           | 章节                                                                                                                                  |
| -------------- | ------------------------------------------------------------------------------------------------------------------------------------- |
| 多媒体内容归档 | 获取与整理、本地视频批量归档、表格批量归档、TikTok 主页批量归档、归档详情与媒体操作、分组管理、英文编辑、图文批量加水印、图文批量配乐 |
| 视频去字幕     | 处理流程、上传后区间编辑、上传后手动框选                                                                                              |
| 视频编辑       | 开始创作与草稿（三步，无分页教学）、编辑工作台                                                                                        |
| 多国语言配音   | 参考音色克隆、在线配音、音色克隆智能分段、在线配音智能分段                                                                            |

- 详情优先当前已打开详情，再取当前页已选作品，最后取当前页第一条；无归档时禁用。英文编辑需要可编辑译文；移动分组步骤需要选中作品；图文章节需要已选适用图文或已打开的真实队列。上传、表格、主页及图文队列忙碌时不接管。
- 草稿教学保留创作、搜索展示、打开管理三步，真实分页功能保留。两种配音主教程均说明智能分段入口，在线语言、音色和参数合为一步；各自的独立章节展示各自弹窗及限制，不借用其他引擎状态。
- `guides.ts`、`detailed-guides.ts` 声明章节版本、步骤 ID、整章或步骤 `context`、`ready` 和可选 `fallbackTarget`。页面通过 `registerGuideContext` 声明 `available` 前置条件、`enter(signal)` 展示逻辑和恢复函数，简单开关使用 `useGuideDialog`。异步只读请求遵守取消信号。
- 适配器不调用会重置输入、切换历史或开始业务的 `show()`；记录原始可见开关、详情引用和临时视图，退出时只恢复接管状态。教程打开的弹窗关闭，用户原本打开的保持打开。英文编辑快照保留未保存输入；图文视图切换隔离预览失效和参考时长监听器，恢复原队列引用、缓存及设置。
- 弹窗使用 `guideDialogBinding` 声明所属上下文。教学期间暂停焦点约束、自动聚焦和 Esc 关闭，由 Driver 接管；已访问且仍在离场动画中的弹窗继续允许。遇到未登记弹窗或确认框则结束当前教学并保留步骤，不主动展示危险确认。
- 气泡层级根据真实弹窗祖先计算；Esc 优先退出。退出恢复焦点约束和键盘焦点，移除会话标记、遮罩与监听器。已有任务不受教学影响。
- 教学弹窗的 `guideDialogBinding(id, opened, aliases?)` 必须传入真实显示状态。关闭期间保留焦点适配，收到 Naive UI `after-leave` 后才释放，避免重建 VFocusTrap 内部结构而中断关闭动画、残留透明遮罩。用户原本打开的弹窗立即恢复普通焦点约束；退出逻辑防止销毁回调重入，并先撤销 Driver 拦截，再恢复弹窗和焦点。
- 修改过的五个原章节升级为版本 2；新章节从版本 1 开始。`editor-workspace` 保持版本 1，保留旧进度；分页教学及闲置锚点已移除。

## 依赖与体积

原有 Naive UI 没有可用的 Tour 导出，且 FloatButton 没有拖动能力，因此补充两个独立依赖，不引入其他组件库。

| 依赖         | 固定版本 | 许可 | 用途                                         |
| ------------ | -------- | ---- | -------------------------------------------- |
| driver.js    | 1.14.0   | MIT  | 高亮遮罩、气泡及步骤导航；开始教程时动态加载 |
| @vueuse/core | 15.1.0   | MIT  | 按导出裁剪的 useDraggable                    |

上游许可证随前端静态资源保留在 `onboarding-third-party-notices.txt`。运行时全部使用本地打包资源，不访问 CDN。锁文件中原有包的解析版本和其他工作区依赖未改变。

本次通过 esbuild 将实际使用的依赖导出按 ESM、minify、split 和 ES2022 独立打包，外置已存在的 Vue，测得：

| 输出内容                    | 压缩前字节 | gzip 字节 |
| --------------------------- | ---------: | --------: |
| useDraggable 及动态加载入口 |      6,139 |     2,749 |
| 按需 Driver.js JS chunk     |     47,075 |    15,443 |
| Driver.js 原始配套 CSS      |      7,539 |     1,917 |

这里是依赖代码的实际独立打包口径，CSS 为上游文件及其 gzip；**不是 npm 包目录大小，也不等于整个应用首页的增量**。项目教程文案、入口及主题代码未计入以上依赖表。

2026-11-26 修复生产构建入口超预算：应用根部通过 `defineAsyncComponent` 独立加载 `GuideCenter`，避免引导目录和相关控件同步进入首页入口包；Driver.js 仍在开始教程时加载。执行 `pnpm build:web`（前端类型检查、Vite 生产构建及现有体积门禁）通过，入口 JS 为 126,619 gzip 字节（限制 153,600），GuideCenter 独立块为 20,909 gzip 字节（限制 76,800），全部 JS 块通过预算。不修改预算阈值；不启动业务模型或制作桌面安装包。

## 检查与用户验收

实施只进行格式、差异、类型及锚点结构检查，没有启动模型、截图或执行功能测试，也未制作安装包或提交发布。

由用户验证：

1. Windows/macOS/浏览器的鼠标及触摸拖动、吸边、误触防护、键盘打开、跨分辨率位置恢复。
2. 侧栏切换、窄窗口、内部滚动及底部安全区下的入口、气泡和弹窗边界。
3. 18 章教程在空列表、已有素材、服务未就绪、任务运行及历史结果状态下的前置说明与定位。
4. 中途退出、继续、重学、完成、Esc、路由取消及目标页面卸载后的状态和焦点恢复。
5. 编辑器全屏、未保存工程及配音引擎切换不影响业务；引导不增加任务、草稿或改变参数。
6. 四个模块、十个功能分组与 18 个章节无遗漏或重复；默认展开、跨模块取消、目录重开和窄屏操作正确，既有学习进度保留。
