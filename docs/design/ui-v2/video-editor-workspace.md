# 独立视频编辑工作台

## 入口与主页

视频与内容菜单中，「视频编辑」位于「视频去字幕」之后。主页 `/tools/video-editor` 沿用蓝紫浅色工具规范，顶部提供导入本地视频、选择归档视频；下方显示最近编辑优先的本地草稿。

草稿支持名称搜索、网格/列表、重命名、复制、删除与继续编辑，显示真实视频画面、名称、时长、最近编辑时间、文件大小和归档关联标识。竖屏封面使用 contain，不拉伸裁切。创建工程后进入 `/tools/video-editor/projects/:projectId`，继续复用现有可调整分区的工作台和所有视频、文本、配乐、水印编辑能力。

主页创作区采用左侧入口、右侧轻量编辑台装饰的蓝紫浅色布局，窄屏隐藏纯装饰。草稿区域使用独立白底面板，工具栏、卡片区、分页分层；前端对已载入草稿进行筛选后分页，默认每页 12 条，可切换 24／48 条。搜索和切换每页数量回到第一页，删除后自动校正页码。重命名弹窗提供关联标签、500 字计数、仅自动聚焦输入框，不选中文本和右对齐操作；提交以保存按钮加载状态反馈，错误保留在弹窗内，不叠加全局进度弹窗。

## 工程与素材归属

工程索引使用 `video-editor-project`；素材清单使用 `video-editor-assets`，文件位于数据目录 `video-editor/items`，不会进入多媒体内容归档列表。本地文件通过现有受限流式上传及 FFmpeg 探测流程进入工程目录，不创建隐藏归档。

归档入口创建独立素材快照，记录归档条目、媒体 ID、校验和与版本。再次从同一归档视频进入时复用工程。草稿复制拥有独立素材和时间线，默认不继承归档回写关联，避免误覆盖。源文件不会被工程删除影响。

继续复用媒体编辑渲染和 Range 播放内核，既有媒体 API 作为兼容接口，通过受控存储分派区分工程素材与归档素材；工程业务 API 位于 `/api/v1/tools/video-editor/projects`。不复制一套渲染器或修改能力包。

草稿自动保存时保留拼接视频及配乐快照，使用 `video-editor-draft-assets` 记录并登记文件索引。项目水印上传长期保留至工程删除或成功转入成品快照，普通归档水印上传继续维持原有 24 小时规则。复制和迁移草稿时为上传水印建立新工程所属引用。

## 编辑区本地素材上传

素材分类提供「上传视频」及「归档导入」，音频分类提供「上传音频」。本地视频沿用 MP4／MOV／WebM 的流式上传、容器校验、FFmpeg 探测和封面生成；独立素材 ID 使用 `editor_material_` 前缀，不进入归档列表或主页草稿列表。上传接口 `/api/v1/tools/video-editor/materials/local-videos` 校验所属工程，并记录素材引用，工程删除时清理无其他工程引用的本地上传源；工程内的视频快照继续按原有草稿保留规则处理。

本地音频使用草稿专属上传接口，支持 MP3／WAV／M4A／FLAC，单文件最大 100 MiB。上传结果和音频文件只保留在当前工程的 `video-editor-draft-assets` 索引及草稿目录，不新增音频素材库记录；未加入时间线的音频也会随草稿保留，复制草稿时一并复制，删除草稿时清理。音频区只展示已上传或已导入的草稿素材；「素材库导入」打开与视频选择器同为 920px 档位的弹窗，提供关键词、音频类型、分组筛选、分页和试听。选择音频后保存工程快照、关闭弹窗并添加到素材区，同一库音频的同一版本不重复导入。上传和导入均不会自动向时间线添加元素，用户点击素材加号后添加。视频和音频均支持多文件逐一上传、弹窗进度及取消；取消或部分失败保留先前完成的素材。

## 保存与归档同步

- 自动保存草稿只保留工程状态，不渲染、不替换归档成品。
- 本地创作使用「保存工程成品」，另有现有导出下载入口。
- 关联归档的工程使用「保存并同步归档」：先生成并保存工程成品，再同步对应归档视频。
- 同步复制已生成的视频及素材快照，更新时长、尺寸、编辑信息、下载地址与封面；归档标题、正文、作者、平台及分组不变，原片保留。
- 同步持有工程与归档的版本锁，使用工程成品版本及归档预期版本校验。归档删除、版本变化或空间不足时明确失败，保留工程及已有归档，支持重试。
- 归档媒体提交与工程同步版本记录在同一数据库事务内完成，重复请求同一已同步版本直接返回，不重复提升版本。
- 渲染、同步和上传使用弹窗进度反馈；同步中不允许离开。返回归档保留原归档列表查询条件。

## 迁移与删除

旧 `/tools/media-archive/video-editor/:itemId/:mediaId` 地址仅负责创建/复用工程并跳转到新模块。原有归档编辑草稿在首次列出时迁入独立工程，迁移标识防止用户删除工程后又自动迁回。尚未过期的上传水印一并迁移；原本已过期的水印不会伪造图片，需要重新选择。

删除工程只删除该工程独立目录、草稿资产索引及其水印上传，不删除归档、用户本地原文件或其他工程素材。工程复制、归档同步和素材读取沿用锁、文件租约、原子清单提交及路径边界规则。
