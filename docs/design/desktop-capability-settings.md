# 桌面设置与能力管理视觉规格

阶段：1（视觉规格）  
目标：为 Windows 桌面版提供单一的应用数据位置说明，以及可选能力的按需管理入口。  
设计基线：沿用现有 Vue + Naive UI、`tokens.css` 色板和工具箱页面组件，不改业务行为。

## 页面框架

设置页在 1440 × 960 桌面窗口中采用两栏结构：左侧设置分区导航固定宽 220 px；右侧主内容最大宽度 1040 px，标题、说明与面板沿用现有 `ToolPageHeader` 和 `workspace-panel` 间距。顶部保留应用品牌与主工具导航。

设置分区顺序固定为：

1. 存储位置
2. 能力管理
3. 启动与更新
4. 迁移与恢复

在窗口宽度小于 900 px 时，左侧分区导航折叠为选择器；内容区保持单列，按钮允许换行，不缩小操作目标。

## 能力管理

页面顶部显示“可选能力”标题、已安装容量汇总与“刷新状态”。其下按用户任务分组展示模块卡片：视频文本解析、在线自然配音、AI 图片处理、参考音色克隆、小红书内容归档和小红书翻译。无须下载的图片压缩、局域网传输与短视频在线解析不显示安装按钮；在线服务注明需要联网。

每张卡片固定展示能力名称、用途、状态、下载大小/安装后占用、所需共享依赖、许可和网络条件。FFmpeg、Python、登录浏览器等共享依赖在模块详情内列出，同时显示“被 N 个能力使用”，避免重复计算下载量。

| 状态 | 卡片内容与可用操作 |
| --- | --- |
| 未安装 | 展示预计下载量、安装后占用和许可；“安装”打开确认对话框。 |
| 下载/安装中 | 进度条、当前步骤、已下载/总量；下载阶段可取消，切换阶段不可取消。 |
| 已安装 | 展示版本、健康状态与最近自检；可“重装”或“卸载”。 |
| 失败 | 保留当前健康版本，显示可读错误及“重试”；不显示原始命令或敏感本机路径。 |
| 受阻 | 说明未满足条件（系统、硬件、正在运行的任务或依赖占用）及解决入口。 |

安装确认框列出模块、自动补装的共享依赖、下载量、安装后空间、联网说明与许可证链接。卸载确认框明确告知“只删除运行时和模型，作品、历史、素材与登录状态保留”；若有正在运行任务或其他能力依赖，则显示阻止原因和依赖项，不提供级联删除。

## 存储位置与迁移

“存储位置”显示安装目录、应用数据根目录及总占用；数据根为安装根下的 `data`，提供“打开目录”。数据目录不可写时提供明确修复说明。

检测到旧版 `%LOCALAPPDATA%\\EcommerceToolboxData` 时，迁移提示在业务工具之前出现。提示源目录、目标目录、所需空间和“旧目录迁移后保留”；用户可选择迁移或明确以空数据启动。进度、校验失败与可恢复状态使用同一页面视觉语言。

## 视觉与交互约束

- 颜色沿用现有 `--color-primary-600: #2563eb`、`--color-local-600: #0d9488`、`--color-text` 与 `--color-border`，仅状态使用现有成功/警告/错误色。
- 卡片沿用现有 12–16 px 圆角与轻阴影；安装状态始终有文字标签，不能只靠颜色或图标表达。
- 安装、重装和卸载操作支持键盘焦点；进度与错误通过可访问文本暴露；禁用状态附带原因。
- 有来源许可信息时可作为参考展示；它不构成内部能力安装门禁。网络发送说明在开始下载前可见。BRIA 权重目前由用户指定本机目录；后续可接入固定资产源，不以许可审批阻塞工程实现。
- 任何安装动作仅由设置页发起；功能页缺少依赖时显示“前往设置安装”，不会启动后台下载。

## 原创图标

概念名：折板星。蓝色与青绿色的两片交错折板形成紧凑容器轮廓，中心以白色四角负形表现工具组合后的产出。采用纯色几何形，不含文字；保留透明圆角外缘，避免复用现有 Lucide `Boxes` 形状。

- 主稿：[1024 px PNG](../../apps/desktop/assets/ecommerce-toolbox-icon-master.png)
- 小尺寸验收：[32 px](../../apps/desktop/assets/ecommerce-toolbox-icon-32.png) · [16 px](../../apps/desktop/assets/ecommerce-toolbox-icon-16.png)
- 已验证主稿为 1024 × 1024，四角透明；小尺寸由同一主稿高质量缩放生成。发布阶段再输出 Windows 多尺寸 `.ico` 并接入安装器、快捷方式、窗口与任务栏。

## 阶段验收

- 模块卡片包含未安装、安装中、失败、可重装和被依赖阻止卸载五种状态。
- 存储、能力管理、启动更新、迁移恢复四个分区顺序已冻结。
- 16 px 与 32 px 图标可辨认蓝/青绿主体和中心负形，透明边缘无黑底。
