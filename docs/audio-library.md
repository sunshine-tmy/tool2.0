# 音频素材库

2026-10-28：原直播音频库增加背景音乐用途，入口更名为音频素材库，原页面地址和播放行为保持不变。支持在归档视频编辑器内选曲或上传，详见[归档配乐与图集生成视频](archive-video-music.md)。旧素材不自动改用途或分组。

实施依据为用户提供的 `PLAN.md`（普通首版计划），未采用针对 GPT-6 Luna 的细化方案。

## 使用方法

1. 打开“多国语言配音 → 参考音色克隆”，在当前批次、历史批次或单段详情点击“加入音频库”。可勾选部分已完成段落，或选择“添加至…”指定分组。
2. 也可以进入“直播音频库”上传本地成品。支持 MP3、PCM WAV、AAC M4A、FLAC，每文件最大 100 MiB，不转换格式，不需要额外安装 FFmpeg。仅音频必填；每个文件均可选填标题、语言、分组、外语文案、中文译文及备注。标题留空使用文件名，语言留空为“未指定”，分组可清空为“未分组”；其余字段留空仍可入库，之后在详情补充文案与备注、通过“移动至”调整分组。多文件各自的分组和备注独立保存。
3. 入库会独立复制音频，带入服务端已保存的外语文案和中文译文；未提交的编辑草稿不参与归档。删除原批次或原批次过期不影响音频库。
4. 缺少任一文案的配音或通用素材显示“待补全”，背景音乐不要求文案。详情里可以校对文案、修改备注，但不会重新生成音频；原始文案保留在来源快照中。
5. 分组最多三级，父分组包括子组素材。移动只修改分类，15 秒内可撤销；删除分组将其全部素材（包括回收站内容）移到“未分组”，不会删除音频。
6. 音频分组中的“播放”在当前条目内独立播放，支持暂停、停止和拖动进度，不修改队列的播放状态、顺序、进度或间隔；若队列也在播放，两者会同时出声。同一列表内只播放一条，切换到另一条会暂停前一条；播放结束不自动切换下一条。条目离开列表或离开模块时停止该条独立音频，不影响队列后台播放。队列支持重复加入、拖动/按钮排序、顺序/列表循环/单曲循环及 0–300 秒间隔。停止会取消后续等待。
7. 播放控件仅显示在直播音频库页面，位于队列列表上方的正常文档流中，不悬浮遮挡页面；展开临时队列会撑开布局。切换到其他模块不显示控件，原有后台播放保持不变；返回音频库可继续控制。刷新或重启恢复队列和位置，但保持暂停。声音由当前设备的默认音频设备输出；不远程控制服务端声卡。
8. 删除先进入回收站，不自动过期；彻底删除不可撤销。完整备份包含回收站、分组、文案和所有音频；恢复采用只新增合并，同 ID/摘要跳过，冲突生成新 ID，同完整分组路径复用。音频列表不提供单条下载，需保存文件时使用“导出所选”或“完整备份”。

### 条目内播放与裁剪

- 每条音频按“文案 / 中间播放与裁剪区 / 右侧分类操作”展示；窄屏时编辑区自动下移，不遮挡文字。
- 每条音频显示真实振幅波形：已播放部分为紫色、未播放部分为灰色。点击波形定位，较长音频可以横向滚动；支持音量、静音、0.5–2 倍速和前后跳转 3 秒。这些设置仅作用于当前条目，不改变队列。
- 点击剪刀进入“裁剪”，拖动波形选区两端调整起止、拖动选区整体移动，或在空白处重新拖选，然后“播放选段”或“另存裁剪音频”。不再显示起止时间输入框或将当前位置设为起止点的按钮。选区至少 0.05 秒，选段播放在终点停止；支持键盘调整播放位置和选区边界。重置按钮恢复全长并退出裁剪。
- “另存裁剪音频”会在同一分组新增 WAV，不覆盖原音频、不替换队列及预设引用。来源记录原音频 ID、版本和裁剪区间；双语文案与备注沿用原内容，需手动校对文案。
- 浏览器本地解码并导出 48 kHz PCM16 WAV，无需额外安装 FFmpeg；仅支持当前浏览器可解码的文件。为避免内存失控，按 48 kHz 双声道预估限制解码规模为 64 Mi 样本（约 11 分钟），过长时提示分段；单个裁剪结果最大 100 MiB。
- 波形在条目进入可见区域附近时加载，使用 8 kHz 解码提取轻量峰值，串行处理并缓存最近 24 条，离开时取消未完成加载。波形解码不自动播放，也不接管队列声音；加载失败可重试，不影响原文件。
- 服务端校验原素材版本、区间、实际 WAV 类型/时长、大小和存储配额，失败清理暂存并保留原库。裁剪音频参与普通分组、播放、回收站、导出备份及恢复。

### 队列列表与预设

- 页面顶部提供“当前队列”和“预设队列”两个列表。当前队列可上移、下移、拖动排序和移除；同一音频可以多次出现。
- 当前队列每条分别显示完整标题、中文译文及外语原文，长文案保留换行、不省略；缺失内容分别提示“暂无中文译文”或“暂无外语文案”。标题与外语相同时仍保留两个字段，列表较长时可滚动查看。
- 点击当前队列或临时队列的某条标题，只将当前播放项定位到该音频开头并保持暂停，不自动播放；同时停止原来的声音和等待倒计时。之后点击主播放器“播放”，按原有队列设置播放。
- 每条右侧提供独立“单次播放”按钮，仅播放这一条一次，播完停止，不进入下一条或循环；暂停/继续仍保持这次单次播放。队列内容、顺序、间隔和循环设置不变。单次播放中可点击“继续队列播放”恢复正常规则；单次播完后再次主动开始播放、点击上一条/下一条或加载预设也使用正常队列规则。
- 点击“保存当前队列为预设”，输入名称，并保存顺序、重复项、播放方式和播放间隔。最多保存 200 个预设，每个最多 200 条。音量和播放进度仍属于当前设备，不写入预设。
- 在“预设队列”里搜索名称、查看内容并点击“加载队列”。有当前队列时会先确认替换；加载停止旧播放及倒计时，从新队列开头保持暂停，不会自动出声。
- “查看内容”按顺序展示每条音频的标题、中文译文与外语原文，方便对照辨认；未填写中文时明确显示“暂无中文译文”。
- 模块内播放器的“临时播放队列”同样展示中文对照；外语原文与标题不同时补充原文，避免重复显示。长文案自动换行，排序和移除按钮独立保留。
- 可重命名预设，或整理当前队列后使用“用当前队列更新”。更新带版本校验，其他客户端已修改时会提示刷新，不会静默覆盖。
- 素材已删除、在回收站或文件不可用时，加载会提示跳过；整张预设都失效时保留原队列。失效引用保留在预设中，素材恢复后可再次加载。
- 删除预设只删除队列编排，不删除音频，也不改变已加载的当前队列。
- 预设与音频库一起永久保存、随完整备份导出恢复；缓存清理和共享数据库重建不会清除预设。选中素材 ZIP 不包含预设。旧版清单/备份没有预设字段时继续正常读取。

## 数据与运维

- 永久数据目录：所连接服务端的 `storageRoot/audio-library`。开发版通常为项目 `storage/audio-library`，桌面版为应用数据根下的 `data/audio-library`。
- `library.json` 为永久恢复清单，`library.json.bak` 为上一版本；`transaction.json` 为提交恢复日志。不要手工修改这些文件或在运行中复制半套文件；跨设备迁移优先使用完整 ZIP 备份。
- 音频位于 `items/<id>/audio.<原格式>`。入库先暂存、校验、同步文件，再提交清单和 SQLite 镜像；异常提交回滚，启动恢复未完成事务。未知孤立资产保留到 `recovery`，不自动清除永久素材。
- 一键全部清理保留整个音频库；即使共享 SQLite 被清除，下次启动也会从永久清单恢复分组、文案、回收站和文件索引。导出期间禁止彻底删除正在导出的素材。
- 容量默认 10 GiB，包含有效素材、回收站和正在导入的预留空间。环境变量 `AUDIO_LIBRARY_MAX_STORAGE_BYTES` 可调整，单位字节。达到上限会拒绝新增，不自动丢弃旧内容。
- 队列与设置保存于各客户端浏览器本地，不进入永久素材备份。网页端与桌面端连接不同数据根时，素材不会自动互相复制，可使用备份恢复或桌面数据迁移。
- 文件缺失时保留文案和来源，显示“音频不可用”。备份发现文件丢失或摘要不符会明确拒绝，避免生成看似成功但不完整的备份。
- 若清单及其备份均损坏，模块返回恢复提示并保留原文件，不会重建空库覆盖。需先保留原目录后从有效备份恢复；此时可用空数据实例导入备份，再通过桌面迁移恢复，不要直接删除原库。
- 已移除自定义标签功能及相关接口、搜索和数据字段。历史清单或 ZIP 备份仍可读取，加载时仅丢弃退役字段，保留音频、文案、分组与队列预设；后续导出不再包含退役字段。

## 接口与安全边界

统一前缀 `/api/v1/tools/audio-library`：素材列表/详情/标注、分组、克隆结果导入、本地上传、批量移动/撤销、回收站、Range 播放、ZIP 导出及备份恢复。

克隆导入只接受批次 ID、段落 ID、版本和目标分组，不接收客户端路径。源读取与重新生成、删除操作串行协调；发生过失败重生成的段落会提示先成功重新生成，避免把新文案与旧音频错误归档。LAN 模式沿用管理员会话与 CSRF 保护，不添加新的访客写权限。

- `pnpm --filter frontend test src/modules/audio-library`
- `node --test scripts/cleanup-engine.test.mjs`
- 构建后：`pnpm --filter backend exec tsx ../scripts/smoke-audio-library.mjs`（临时数据、真实 Chrome 页面验收；截图在 `output/playwright/audio-library`）
- `pnpm desktop:make`：生成 Windows 桌面安装包，功能与网页端共享实现。

当前不包含同句话的跨语言关联、响度统一、静音裁剪、直播快捷键、输出设备选择或 OBS 接入。
