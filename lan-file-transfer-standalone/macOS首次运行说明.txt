macOS 首次运行说明
==================

通过微信、浏览器或网盘接收压缩包后，推荐直接使用下面的终端方法。
它可以同时解决“身份不明的开发者”和“没有正确的访问权限”两类提示。

1. 打开 macOS 自带的“终端”。
2. 输入 cd 和一个空格：

   cd 

3. 把解压后的 lan-file-transfer-standalone 文件夹拖进终端窗口，然后按回车。
4. 复制下面整行命令到终端并按回车：

   xattr -dr com.apple.quarantine . && chmod +x ./*.command ./scripts/*.sh && ./macOS一键启动.command

首次成功启动后，以后可以直接双击启动和停止文件。
请只对确认来自可信来源的压缩包执行解除隔离命令。

如果双击 macOS一键启动.command 后出现：
“Apple 无法验证此文件是否包含可能危害 Mac 安全或泄漏隐私的恶意软件”，
这是 macOS 对从网络下载且未经过 Apple 公证的脚本进行的首次安全拦截，不是项目运行错误。

请按以下步骤仅放行一次：

1. 在警告窗口中点击“完成”，不要选择“移到废纸篓”。
2. 打开苹果菜单 →“系统设置”→“隐私与安全性”。
3. 向下找到“安全性”，点击与 macOS一键启动.command 对应的“仍要打开”。
4. 输入 Mac 登录密码并确认打开。
5. 以后可以直接双击 macOS一键启动.command；如果首次双击 macOS一键停止.command 时也出现提示，按相同步骤放行一次即可。

如果“仍要打开”没有出现，请先重新双击一次 macOS一键启动.command，再立即返回上述设置页面。
Apple 通常只在尝试打开后的约一小时内显示该按钮。

如果提示“文件无法执行，因为你没有正确的访问权限”：

这表示传输或解压过程丢失了脚本的可执行权限。打开“终端”，输入下面命令并保留末尾空格：

   chmod +x 

把启动文件拖入终端窗口并按回车，然后重新双击。停止文件首次使用前也按同样方法处理。

分享给 Mac 时建议直接发送并在 Mac 上解压 `lan-file-transfer-standalone-macos.tar.gz`，不要先在 Windows 解压后再发送文件夹，也不要通过聊天软件单独发送 `.command` 文件。

运行环境：

- Apple M 系列 ARM64 芯片
- Node.js 20、22 或 24，推荐 Node.js 22 LTS

文件传输和图片压缩不需要 Python。
需要 AI 图片处理时进入对应页面点击一键安装；系统会在需要时打开根目录中的 `python-3.11.9-macos11.pkg`。

首次启动只安装 Node.js 依赖，不会自动安装 AI 环境。AI 安装后优先使用 Apple MPS，不支持的算子会自动回退 CPU。
